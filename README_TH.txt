AUTO SHORTS AI — FINAL 16:9 CREATIVE REFERENCE EDITION
====================================================

มาตรฐานของรุ่นนี้
- วิดีโอแนวนอน 16:9 ขนาด 1920x1080, 30 FPS
- ตัวละครประจำช่องใช้ภาพ PNG โปร่งใสจาก Character Reference จริง ไม่ให้โมเดลวาดตัวละครใหม่
- ฉากหลังสร้างใหม่ตามเนื้อหาแต่ละฉาก ไม่จำกัดว่าต้องเป็นทะเล ชายหาด หรือสถานที่ในภาพต้นแบบ
- สีของฉากเลือกตามวัตถุ สถานที่ เวลา และอารมณ์ของเรื่อง ไม่มีชุดสีบังคับ
- คงลายเส้นดินสอสี/สีเทียนแบบวาดมือ เส้นดำไม่เรียบ รอยระบาย และความไม่สมบูรณ์แบบตามภาพต้นแบบ
- บางฉากสามารถมีข้อความสั้น ๆ ที่เป็นส่วนหนึ่งของภาพได้ โดยโปรแกรมวางข้อความภาษาไทยลงบนภาพ ไม่ใช่ Subtitle

ภาพอ้างอิง
- assets/character_reference.png: ชีตตัวละครต้นฉบับ
- assets/characters/pose_1.png ถึง pose_8.png: ภาพตัวละคร 8 ท่าที่ตัดและทำพื้นหลังโปร่งใส
- assets/background_style_reference.png: ภาพตัวอย่างลายเส้นและเทคนิคฉาก

การเลือกท่าตัวละคร
- บทแต่ละฉากสามารถระบุ pose ได้: neutral, friendly, side, back, explain, walk, point, surprised
- หากโมเดลไม่ส่ง pose ระบบจะพยายามอนุมานจากบทและ image_prompt
- ท่าที่มีให้เลือกยังจำกัดอยู่ใน 8 ภาพอ้างอิง ไม่สามารถสร้างท่ากายวิภาคใหม่ได้โดยไม่เพิ่มภาพต้นแบบท่าใหม่
- ตำแหน่งตัวละครสลับซ้าย/ขวาและขนาดเล็กน้อย พร้อมสั่งให้ภาพพื้นหลังเว้นพื้นที่ฝั่งนั้น แต่ควรตรวจว่าตัวละครไม่บังวัตถุสำคัญ

ข้อความในภาพ
- image_text เป็นข้อความสั้นภาษาไทย ไม่เกิน 48 ตัวอักษร
- เว้นว่างเมื่อไม่จำเป็น
- ใช้ฟอนต์ Noto Sans Thai Bold วางเป็นส่วนหนึ่งของภาพก่อนทำวิดีโอ
- คำสั่งสไตล์เสียงส่งผ่าน speechMetadata แยกจากบทพูด เพื่อไม่ให้โมเดลอ่านคำสั่งสไตล์ออกเสียง

ระบบเสียงพากย์ (เรียงลำดับสำรอง)
1. Gemini 3.8 Flash TTS (`gemini-3.8-flash-tts`) เป็นตัวหลัก เน้นคุณภาพเสียง การแสดงอารมณ์ และการกำกับน้ำเสียง
2. Gemini 3.8 Flash-Lite TTS (`gemini-3.8-flash-lite-tts`) เป็นตัวสำรอง Gemini เมื่อรุ่นหลักผิดพลาดที่ไม่ใช่โควตา
3. Microsoft Edge TTS (`th-TH-NiwatNeural`) เป็นตัวสำรองสุดท้าย เมื่อ Gemini ทั้งสองรุ่นผิดพลาดที่ไม่ใช่โควตา
- หาก Gemini ตอบ HTTP 429 ระบบหยุดทันที ไม่ลอง Gemini รุ่นถัดไปหรือ Edge TTS เพื่อไม่สลับบริการหลบข้อจำกัดโควตา
- ใช้เสียง Gemini ที่กำหนดใน `VOICE_NAME` (ค่าเริ่มต้น `Enceladus`); Edge ใช้เสียงไทย `th-TH-NiwatNeural`
- Workflow ติดตั้ง fonts-noto-core และ Pillow เพื่อรองรับการวางข้อความภาษาไทย

ข้อจำกัดที่ต้องเข้าใจ
- Pollinations endpoint ที่ใช้ในโปรเจกต์รับ Prompt แบบข้อความ ไม่ได้ส่งไฟล์ background_style_reference.png เข้าโมเดลเป็นภาพอ้างอิงโดยตรง
- ภาพ Background Reference จึงใช้เป็นมาตรฐานให้ Prompt อธิบายเทคนิคและลายเส้น ไม่ใช่การ image-to-image และไม่รับประกันว่าฉากใหม่จะเหมือนต้นแบบทุกพิกเซล
- ตัวละครถูกวางจาก PNG ต้นฉบับจริง จึงคงรูปหน้าและทรงผมได้มากกว่าการให้ AI วาดเอง แต่ท่าทางถูกจำกัดตามภาพต้นแบบ 8 ท่า
- ระบบสลับด้านตัวละครและแจ้งพื้นที่ว่างใน Prompt เพื่อช่วยหลีกเลี่ยงวัตถุหลัก แต่ไม่มีระบบ Computer Vision ที่รับประกันว่าไม่บังวัตถุในทุกภาพ
- image_text เป็นข้อความที่โมเดลเลือกเสนอและระบบวางลงภาพ ต้องตรวจการสะกดและความเหมาะสมก่อนเผยแพร่
- การทดสอบ Offline ไม่สามารถรับรองโควตา ความพร้อมให้บริการ หรือผลภาพจาก Pollinations/Gemini ในวันที่รันจริง
- Preflight ภาพเป็น Offline แล้ว ไม่ยิงคำขอสร้างภาพทดสอบ จึงไม่กินโควตาภาพก่อนเริ่ม แต่ถ้าบริการภาพล่มหลังจากสร้างบทแล้ว อาจเสียคำขอ Gemini สำหรับบทไปก่อน
- ผู้ให้บริการอาจเปลี่ยนโควตา เงื่อนไข หรือราคาได้ คำว่า Free Tier ไม่ได้หมายความว่ารับประกันโควตาหรือความพร้อมให้บริการตลอดเวลา

การหยุดเมื่อถูกจำกัด
- Gemini HTTP 429: หยุดทันที ไม่ลองโมเดลสำรองทั้งงานเขียนบทและ TTS (รวมถึง Edge TTS)
- Pollinations HTTP 402/403/429: หยุดทันที ไม่ retry และไม่ใช้ภาพฉากอื่นแทน
- ไม่มีการสลับไปใช้ Cloudflare หรือบริการภาพอื่นโดยอัตโนมัติ

เริ่มใช้งาน
1. อัปโหลดไฟล์ทั้งหมดจาก ZIP ไปยัง Root ของ Repository โดยคงโฟลเดอร์ assets และ .github ไว้
2. ตรวจ Settings > Secrets and variables > Actions ว่ามี GEMINI_API_KEY อยู่แล้ว ไม่ต้องส่งค่า Secret ให้ใคร
3. เปิด Actions > make-short > Run workflow
4. รอบแรกไม่ต้องติ๊ก resume และไม่ต้องติ๊ก publish_draft
5. รอ job make ผ่าน QC แล้วดาวน์โหลด Artifact ชื่อ auto-shorts-output-...
6. ตรวจ output.mp4, title.txt และ notes.md ก่อนนำไปเผยแพร่

ความปลอดภัยและค่าใช้จ่าย
- ไม่มีขั้นตอนเปิด Billing หรืออัปเกรดแผน
- Workflow ทำงานเมื่อกด Run workflow เท่านั้น ไม่มี Schedule อัตโนมัติ
- ผลลัพธ์ส่งเป็น Artifact เป็นค่าเริ่มต้น
- GitHub Draft Release แยกเป็น job และปิดเป็นค่าเริ่มต้น ต้องเลือก publish_draft เอง
- Job สร้างคลิปใช้ contents: read; สิทธิ์ contents: write อยู่เฉพาะ job Publish Draft ที่เลือกเปิดเอง
- ไม่มีขั้นตอน Commit หรือ Push
- การกด Run workflow จะเรียกบริการภายนอกจริง (Gemini, Wikipedia, Pollinations และอาจใช้ Edge TTS) และใช้โควตาตามการใช้งาน แม้ไม่ได้เปิด Billing
- ผู้ช่วยไม่ได้เรียก API จริงหรือรัน GitHub Actions ในการตรวจสอบรุ่นนี้
