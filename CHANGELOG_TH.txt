AUTO SHORTS AI — รายการเปลี่ยนแปลง Offline
วันที่: 25 พฤศจิกายน 2026

1) Image Provider
- ยกเลิก Pollinations anonymous endpoint ที่เคยตอบ HTTP 402 ซ้ำ
- เพิ่ม Cloudflare Workers AI FLUX.2 Klein 4B ผ่าน multipart/form-data
- ใช้ CLOUDFLARE_ACCOUNT_ID และ CLOUDFLARE_API_TOKEN จาก GitHub Secrets
- หากไม่มี credentials จะหยุดก่อนเรียก Gemini เพื่อไม่ใช้โควตาโดยเปล่าประโยชน์
- 402/403/429 หยุดทันที; 5xx/network error retry ได้อีกหนึ่งครั้ง
- ไม่เรียก API จริงในงานปรับปรุงครั้งนี้

2) Image integrity / Resume
- ลบ preflight ที่ยิงคำขอสร้างภาพจริง
- เพิ่ม marker ที่บันทึก SHA-256, scene fingerprint และ provider
- Checkpoint เปลี่ยนเป็น version 2 และปฏิเสธ checkpoint version 1
- Resume ใช้ภาพเดิมเฉพาะเมื่อ scene hash และ image hash ตรงกัน
- หากภาพฉากใดล้ม ให้หยุดทันที ไม่แทนด้วยภาพก่อนหน้าหรือพื้นสี

3) Wikipedia
- เพิ่มการตรวจความเกี่ยวข้องโดยต้องพบคำสำคัญทั้งหมดใน lead สำหรับ redirect/ชื่อทางเลือก
- ยังคงปฏิเสธบทความสื่อบันเทิง/มังงะ/ภาพยนตร์/เกม ฯลฯ

4) QC
- ตรวจ image signature, marker, SHA-256 และ aspect ratio 9:16 ด้วย FFprobe
- คง Final MP4 QC เดิม

5) Workflow / Documentation
- เพิ่ม Cloudflare Secrets ใน step สร้างคลิป
- เพิ่ม checkpoint.json ใน Diagnostics Artifact
- ปรับ README_TH.txt ให้ตรงกับข้อกำหนดใช้ฟรีและสถานะการทดสอบ
